## Organização sugerida para novos envios

Para facilitar futuras atualizações, o ideal é manter nomes descritivos e curtos:

- `fachada-*.jpeg`
- `interior-*.jpeg`
- `nr-*.jpeg`
- `uniformes-*.jpeg`
- `epis-*.jpeg`

## Observação

Os arquivos brutos da câmera ou do WhatsApp podem continuar aqui como acervo, mas o site deve apontar apenas para as imagens selecionadas acima.
